🚀 Excited to launch Nova — an AI-powered Chrome Extension (Manifest V3) for high-speed page intelligence, web scraping, and developer productivity!

💡 Why I built Nova:
Extracting insights and structured data from the web often requires juggling multiple disjointed extensions. Nova brings AI comprehension and extraction workflows directly into a single, clean workspace.

✨ Core Features:
✦ Groq AI Inference: 1-click executive summaries, deep Q&A, and Text-to-Speech audio readback.
✦ Smart HTML Scraper: Auto-detects tables and web data with instant exports to Excel (.csv/.xls), formatted PDF, and JSON.
✦ High-Res Tab Capture: Instant screenshot engine with clipboard copy.
✦ Productivity Suite: Integrated Eyedropper color sampler, URL tracking cleaner, and domain-synced quick notes.

🧠 What I Learned:
• Manifest V3 Architecture: Event-driven background service workers, asynchronous cross-context messaging, and strict CSP handling.
• Fast AI Integration: Streamlining sub-second LLM inference via Groq Cloud APIs and dynamic DOM-context extraction.
• Client-Side Data Engineering: Parsing nested HTML tables and generating UTF-8 BOM Excel exports & formatted print-ready PDFs directly in the browser.
• State & Storage: Managing seamless browser sync and preferences with chrome.storage.sync.

🛠️ Built with: Vanilla JavaScript, Chrome Extension Manifest V3 APIs, Groq REST API, and Custom CSS Glassmorphism.

🔗 GitHub Repository: https://github.com/Olied-Ahmed-chowdhury/nova-chrome-extension

I’d love to hear your feedback! Let me know your thoughts in the comments. 👇
